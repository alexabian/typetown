# TypeTown

TypeTown is a kid-friendly typing and learning game built with Vite.

## Scripts

- `npm run dev` — start the Vite dev server
- `npm run build` — create a production build in `dist/`
- `npm run preview` — preview the production build locally

## Structure

- `index.html` — Vite entry document
- `src/main.js` — app bootstrap + game logic
- `src/app-template.js` — app markup template
- `src/style.css` — app styles
- `legacy/typetown-single-file.html` — original single-file version kept as reference
